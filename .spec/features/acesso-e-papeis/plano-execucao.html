Como executar — via agente

Peça ao agente (Claude Code) para executar o plano. Ele roda:

bash .spec/features/acesso-e-papeis/executar-tarefas.sh

Este arquivo é só visualização. Cada faixa roda claude -p num worktree próprio, com contexto limpo, modelo e esforço já definidos. O gate final (verify + audit) roda sozinho; a execução fica em background e, a cada 1 minuto, o agente posta no chat a tabela de andamento (onp-spec resumo acesso-e-papeis --tabela) e o resumo geral de andamento (onp-spec resumo acesso-e-papeis).
